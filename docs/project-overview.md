# Family Care Cloud ☁️

여러 가족이 번갈아 어르신을 돌볼 때, **돌봄 기록을 함께 남기고 다음 보호자에게 전달하는 서비스**입니다.

## 왜 만드나요?

병원에 다녀온 내용, 다음 진료 일정, 식사나 복약 확인이 전화와 메신저에 흩어져 있으면 보호자가 바뀔 때마다 다시 설명해야 합니다.

우리는 이 기록을 한곳에 모아, 다음 보호자가 최근 상황과 챙길 일을 쉽게 알 수 있도록 하려 합니다.

## 어떻게 사용하나요?

1. 보호자가 병원 방문 결과나 일상 돌봄 내용을 기록합니다.
2. 가족이 시간순으로 쌓인 기록과 일정을 함께 확인합니다.
3. 담당 보호자가 바뀌면 AI가 최근 기록과 확인할 일을 요약해 줍니다.

예를 들어, “오늘 내과 방문. 약 변경 없음. 다음 진료 때 혈액검사 예정”이라는 기록을 남기면 다음 보호자가 이를 확인하고 다음 방문을 준비할 수 있습니다.

AI는 저장된 기록을 정리하고 안내하는 역할을 맡습니다. 의료 판단이나 복약량 변경을 직접 결정하지 않습니다.

## 현재 진행 상태

현재는 **프론트엔드 프로토타입 개발 단계**입니다. React 기반 임시 화면과 가상 데이터 흐름을 구성했으며, 디자인 검토와 실제 백엔드 API 연결은 후속 단계입니다.

- 참여 인원: 5명 — 기획 2명, 프론트엔드 1명, 백엔드 2명(이 중 1명은 AI 담당)
- 프로젝트 마감: 2026년 9월 22일
